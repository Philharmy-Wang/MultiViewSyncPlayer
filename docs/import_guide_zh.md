# 视频导入教程

> 逐步引导你将散落的视频文件导入 MVSP 媒体库。

## 前置条件

- 已安装 MVSP（参见 [快速开始](../README_zh.md#快速开始)）
- 准备好视频文件（支持 mp4, avi, mkv, mov 等格式）

## Step 1：打开导入向导

菜单栏 **文件 -> 导入视频到库**（快捷键 `Ctrl+I`），或左侧媒体库浏览器点击 **+ 导入** 按钮。

<!-- 截图占位：import_wizard_step1.png -->

## Step 2：选择库根目录

选择一个文件夹作为媒体库根目录。MVSP 会在该目录下自动创建四层结构：

```
<library_root>/
├── <实验名>/
│   └── <日期 YYYY-MM-DD>/
│       └── <个体 ID>/
│           ├── _meta.json
│           └── *.mp4
```

可以复用已有的库目录，不会影响已有数据。

## Step 3：添加源文件

将视频文件拖入列表，或点击「添加文件」「添加文件夹」。

支持批量操作：
- 拖入一个文件夹 → 自动扫描其下所有视频文件
- 可混选不同格式的文件

## Step 4：填写元数据

- **实验名称**：如 `ThreeChamber`、`OpenField`
- **日期**：ISO 格式 `YYYY-MM-DD`
- **个体 ID**：如 `24332`、`Baboon-01`
- **备注**：可选

## Step 5：指定视角映射

为每个视频文件分配视角方向和编号：

| 视角方向 | 说明 |
|---|---|
| front | 前方机位 |
| back | 后方机位 |
| left | 左侧机位 |
| right | 右侧机位 |
| top | 顶部机位 |
| bottom | 底部机位 |

系统会根据文件名自动推测视角方向（如 `前-1.mp4` → front #1），你也可以手动调整。

每个视角会自动分配一个标识色，方便在播放器中区分。

## Step 6：选择导入模式 & 预览

| 模式 | 说明 |
|---|---|
| **复制** | 将文件复制到库目录（默认，最安全） |
| **硬链接** | 创建硬链接（不占额外磁盘，但要求同卷） |
| **移动** | 将文件移入库目录（源文件会被移走） |

预览区会显示最终的文件路径映射，确认无误后点击「开始导入」。

## Step 7：完成

导入完成后，左侧媒体库浏览器会自动刷新，展示新导入的实验/个体。

双击个体节点即可加载全部视角开始同步对齐！

---

## 常见问题

**Q: 文件名没有方向信息怎么办？**
A: 系统会列为「未分配」，你可以手动指定方向，或跳过不导入。

**Q: 导入一半取消了？**
A: 未完成的文件不会被纳入索引，可以安全重试。

**Q: 能否修改已导入的视频？**
A: 当前版本暂不支持编辑已导入的条目，请删除后重新导入。
